# Inbox

Zona de aterrizaje. Todo lo que no sabes dónde va, entra aquí (capturas, sugerencias de Slack de las tareas automáticas, borradores). Se vacía una vez por semana: cada nota se clasifica a su carpeta o se borra. Si algo lleva 2 semanas aquí, probablemente no importaba.
